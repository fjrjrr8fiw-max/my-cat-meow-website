# ЗооДом — новый визуальный концепт

Многостраничный статический сайт на HTML, CSS и JavaScript. Страницы переключаются по hash-ссылкам.

## Запуск

Откройте папку `site-redesign` в VS Code и запустите `index.html` через Live Server. Либо из терминала в этой папке выполните:

```powershell
python -m http.server 4173
```

Откройте `http://localhost:4173`.

## Разделы

- Главная с авторской пиксельной иллюстрацией кота, который смотрит на звёзды
- О гостинице
- Услуги и цены
- Дополнительный уход
- Фотоальбом
- Контакты

У каждой страницы свой мягкий фон и пастельный цветовой акцент. В галерее используются фотографии с публичного сайта `zoodom.od.ua`, сохранённые локально в `assets/`. Цены и контакты перенесены из информации на сайте; актуальность стоит подтвердить у гостиницы.

Заявки отправляются напрямую по телефону и ссылкам на мессенджеры. Серверной формы и автоматических уведомлений нет.
